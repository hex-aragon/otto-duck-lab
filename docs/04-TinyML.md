## 2. 파이프라인 (1번 자세 분류, 이미 구현됨)

```
① 보드가 200ms마다 특징 8개 계산 (posture.h FeatureWindow::features)
② 웹에서 라벨 고르고 "기록" → 0x92 패킷을 라벨과 함께 저장
③ 웹에서 학습: 8 → 12(ReLU) → 클래스 수(softmax), Adam, 300 epoch, 80/20 검증
④ posture_model.h 내보내기 → firmware/otto_nu40/ 에 복사 → 업로드
⑤ 펌웨어가 헤더를 자동 감지(__has_include)해 규칙 대신 모델 사용. 웹 상태 칸에 "TinyML 모델" 표시
```

모델 크기: 가중치 8×12 + 12 + 12×6 + 6 = 186개 ≈ 0.7KB. 추론 수 µs 수준이라 샘플링에 영향 없다.

### 특징 8개 (보드와 웹이 같은 정의를 써야 한다)

| # | 값 | 무엇을 구분하나 |
|---|---|---|
| 0~2 | 가속도 x, y, z 평균 | 중력 방향 → 서 있음 / 넘어진 방향 |
| 3~5 | 가속도 x, y, z 표준편차 | 걷기 흔들림 vs 손에 들려 흔들림 |
| 6 | 자이로 크기 평균 ÷100 | 회전량 |
| 7 | 가속도 크기 최대 | 충격 |

특징을 바꾸면 `posture.h`, 웹 `FEATURE_COUNT`, 학습 데이터를 모두 다시 맞춰야 한다.

### 데이터 모으는 법

| 라벨 | 어떻게 | 주의 |
|---|---|---|
| 0 서 있음 | 바닥에 세워 둠, 책상 살짝 치기 | 정지 상태만 모으면 걷기와 경계가 약해진다 |
| 1 걷는 중 | 앞 · 뒤 · 돌기 · 춤을 섞어서 | 동작별로 골고루 |
| 2 · 3 · 4 넘어짐 | 손으로 눕혀 두기 + 넘어지는 순간 | 1초 창이라 넘어지는 순간과 누워 있는 상태가 섞인다 — 둘 다 넣는다 |
| 5 들어 올림 | 손에 들고 걷기 · 흔들기 · 가만히 들기 | 가만히 든 것은 "서 있음"과 거의 같다 → 모델 한계로 기록 |

라벨당 **30개 이상** (기록 6초 이상). 가능하면 **사람 2명이 따로 모은 데이터로 검증**한다 (같은 사람 데이터만 쓰면 정확도가 부풀려진다).

### 평가 기준

| 지표 | 목표 |
|---|---|
| 검증 정확도 | 90% 이상 |
| 넘어짐 → 서 있음 오판 | 0에 가깝게 (안전에 직접 영향) |
| 서 있음 → 넘어짐 오판 | 적게 (잦으면 로봇이 자꾸 멈춤). 펌웨어는 2회 연속일 때만 확정 |
| 실물 넘어짐 감지 지연 | 1초 이내 |

웹 학습 화면의 혼동 행렬로 확인하고, 실물에서 10번씩 넘어뜨려 감지 횟수를 기록한다.

## 3. Edge Impulse로 비교해 보기 (공부용)

직접 만든 학습기와 같은 데이터로 Edge Impulse를 써서 결과를 비교한다. 업계에서 많이 쓰는 흐름을 익히는 목적.

1. 펌웨어 `#define DEBUG_RAW 1` → 시리얼로 `ax,ay,az,gx,gy,gz` 25Hz CSV
2. `npm install -g edge-impulse-cli` → `edge-impulse-data-forwarder`
3. Impulse: 시계열 1000ms 창 → Spectral Analysis → Classification
4. 배포: Arduino library → `classifyPosture()` 안에서 `run_classifier()` 호출로 교체
5. 비교 표: 정확도 · 모델 크기 · 추론 시간

nRF52840(Cortex-M4F)은 Edge Impulse가 공식 지원하는 Nano 33 BLE Sense와 같은 칩이라 돌아갈 것으로 보지만, 누코드 BSP에서 그 라이브러리가 컴파일되는지는 `TODO: 확인 필요`.

## 4. 2단계와 이어지는 점

| 오또에서 한 것 | Open Duck Mini · Microduck에서 |
|---|---|
| 특징 → 작은 신경망 → C 배열 → 보드 | 관측 → 정책 신경망 → ONNX → 파이/NPU |
| 학습/검증 나누기, 혼동 행렬 | 시뮬레이션 보상 곡선, 실물 시험 기록 |
| 데이터 분포 차이(사람마다 다름) | sim2real 차이, 도메인 랜덤화 |
