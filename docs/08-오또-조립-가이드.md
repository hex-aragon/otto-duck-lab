# 오또 DIY 조립 가이드 (매뉴얼 ㉗~㉛)

현재 상태(11/18 사진 기준): 몸체 안에 골반 서보 2개, 다리 2개에 발 서보 장착, 초음파 센서 앞판 장착. 보드는 아직 밖. ㉗부터 진행.
11/18 점검 목표: **서보 4개 90° 정렬 → 아래 "걷기 테스트"로 실제로 몇 걸음 걷기**. 안 되면 춤·제자리 동작만으로 데모.

## 0단계: 다리 붙이기 전에 서보 90° 맞추기
가장 흔한 실수. 90°에 맞추지 않고 혼을 끼우면 다리가 틀어져 걷지 못한다. 이미 끼운 발 쪽 혼도 확인할 것.

1. 나노를 USB로 연결. IDE에서 Board `Arduino Nano`, 업로드 실패하면 Processor `ATmega328P (Old Bootloader)`. CH340 드라이버 필요할 수 있음.
2. 서보 4개를 확장보드에 꽂기: **갈색 → G, 빨강 → V, 주황 → S**
3. `firmware/servo_center/servo_center.ino` 업로드. 핀 대응(2번 서보 → D2 …)은 추측이니 실제 움직임으로 확인.
4. 모두 90°에서 멈춘 상태에서 혼 끼우기
   - 골반 서보(몸체 안 2개): 발끝이 정면을 향하게
   - 발 서보(다리 안 2개): 발바닥이 바닥에 평평하게. 기울면 혼 나사 풀고 한 칸씩 돌려 다시 끼우기

USB 전원만으로는 서보 4개 동시 구동 시 리셋될 수 있음 → 떨리면 배터리 연결.

## ㉗ 다리를 몸체에 고정
- 몸체 아래로 나온 골반 서보 혼에 다리 윗판을 맞추고 3×6mm 나사로 고정 (㉖과 같은 방식)
- 서보 선은 몸체 바닥 구멍으로 넣어 위로. 왼쪽은 왼쪽, 오른쪽은 오른쪽 구멍으로 (엇갈리지 않게)

## ㉘ 배선 (회로도 기준)
| 부품 | 연결 위치 |
|---|---|
| 서보 ②③④⑤ | 0단계에서 확인한 핀. 정면 기준 ③ 왼쪽 위, ② 오른쪽 위, ⑤ 왼발, ④ 오른발 |
| 초음파 | Trig·Echo·5V·GND → 회로도의 센서 핀 열 |
| 도트매트릭스 | CLK·CS·DIN·5V·GND → 회로도 왼쪽 핀 열 |
| 블루투스 | 보드 오른쪽 4핀 BT 헤더에 라벨끼리 그대로 (TX→TX, RX→RX) |
| 부저 | 보드 아래쪽 핀 열의 부저 SIG/GND |
| 배터리 | 스위치 거쳐 보드 전원 단자. **극성 꼭 확인** |

- 초음파·도트·부저의 정확한 핀 번호는 회로도 사진에서 안 읽힘 → 보드 인쇄(D8, D9 …)와 elscience.co.kr 예제 코드의 `#define` 핀 번호를 맞춰 볼 것
- **BT 모듈 꽂은 채로는 업로드 불가** (D0/D1 공유). 업로드 때 빼고, 끝나면 다시 꽂기

보드는 양면테이프로 몸체 윗면 안쪽에, 초음파 센서가 앞쪽 위로 오게.

## 걷기 테스트 (㉗ 다리 고정 + 서보 4개만 연결한 상태에서, 몸체 닫기 전)
초음파·도트·BT·부저는 아직 안 꽂아도 된다. 보드는 몸체 밖에 두고 선만 길게 빼서 테스트.

스케치: `firmware/otto_nano_walk/otto_nano_walk.ino` (걸음 계산은 NU40용과 같은 `gait.h`). 시리얼 모니터 **9600bps, 줄 끝 NL**.

1. **배터리 연결**하고 업로드. 걷기는 USB 전원만으로는 리셋되기 쉽다.
2. `i` → 서보가 하나씩 흔들리며 "D2 → 왼다리(골반)" 식으로 출력. 실제 움직이는 관절이 다르면 스케치의 `PINS` 순서를 고친다. **왼쪽/오른쪽은 로봇 자신 기준**(로봇 등 뒤에서 봤을 때).
3. `h` 차렷 상태에서 눈으로 확인 → 어긋난 관절만 트림
   - 골반: 발끝이 정면을 향하도록 `t 0 -5`, `t 1 3` …
   - 발: 발바닥이 바닥에 평평하도록 `t 2 4`, `t 3 -2` …
   - 트림이 ±15° 넘게 필요하면 혼을 한 칸 옮겨 다시 끼우는 게 낫다 (서보 여유가 줄어듦)
   - 맞으면 `save`
4. **공중 테스트**: 몸체를 손으로 들고 `a 60`, `w 2`. 확인할 것
   - 발 서보: 한쪽 발이 바깥으로 기울며 몸을 들 때, 다른 쪽이 반대로 → 둘이 "같은 쪽으로 몸을 기울이는" 방향이어야 함
   - 골반: 들린 다리가 앞으로 나가야 함
   - 어느 하나가 반대로 움직이면 그 서보의 `REVERSE`를 `true`로
5. **바닥 테스트**: 평평하고 미끄럽지 않은 곳(책상 매트 OK, 유리 X). `a 60` `w 4` → 되면 `a 80` → `a 100`
6. `b` 뒤로, `l`/`r` 돌기, `u` `s` `m` `k` 춤 동작 확인. 멈추기는 `x`, 힘 빼기는 `off`

### 걷기가 이상할 때
| 증상 | 먼저 볼 것 |
|---|---|
| 제자리에서 발만 동동, 앞으로 안 감 | 발 진폭 부족 → `a 100`, 바닥 미끄러움, 발 트림 |
| 한쪽으로 계속 돈다 | 골반 트림 (도는 반대쪽 다리 트림 조정) |
| 옆으로 넘어진다 | 발 트림, `p 1200`으로 천천히. 몸체 안 배터리·보드 위치를 가운데·아래로 |
| 뒤로 간다 | `w`/`b`가 반대 → 발 서보 두 개 다 `REVERSE` 확인 |
| 움직이다 보드 재시작 (처음 메시지가 다시 뜸) | 배터리 약함 / USB만 연결 |

## ㉙ 부저·도트매트릭스 장착
- 도트매트릭스: 앞판 사각 구멍, 초음파 "눈" 아래
- 부저: 매뉴얼 사진 위치(보드 옆 빈 공간)

## ㉚~㉛ 정리하고 닫기
- **닫기 전에** 예제 코드로 걷기·초음파·도트·부저 각각 확인 (닫았다 다시 열면 핑거조인트 헐거워짐)
- 남는 선은 절연테이프나 케이블타이로 묶어 서보 회전부에 걸리지 않게

## 막혔을 때
- 서보 떨림 / 보드 리셋 → 배터리 전압 부족이거나 USB 전원만 쓰는 중
- 업로드 실패 → BT 모듈 뺐는지, Old Bootloader로 바꿔 봤는지
- 걸을 때 한쪽으로 쓰러짐 → 0단계 혼 각도 문제. 혼을 한 칸씩 다시 끼우거나 코드의 trim(보정값)으로 조정
