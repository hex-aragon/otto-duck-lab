## 2. 배선

```
                     ┌──────────────────────────┐
[배터리] ─ 스위치 ─┬─│ 5V BEC ─ 5V ─┬─ 서보 4개 빨간선(+)   │
                   │ └──────────────┼───────────┘
                   │                └─ GND ─┬─ 서보 4개 갈색선(−)
                   │                        └─ NU40 GND  ← GND는 반드시 묶는다
                   └─ (보드 전원 입력: TODO 확인 필요)

NU40 DK  P0.02 ─ 왼다리  신호(주황)
         P0.03 ─ 오른다리 신호
         P0.04 ─ 왼발    신호
         P0.05 ─ 오른발   신호
         SDA(P0.26) / SCL(P0.27) / 3V3 / GND ─ IMU
```

| 연결 | NU40 DK 핀 | 코드 위치 | 상태 |
|---|---|---|---|
| 왼다리(고관절) | P0.02 | `SERVO_PINS[0]` | `TODO: 확인 필요` — 헤더에 나와 있는지 |
| 오른다리 | P0.03 | `SERVO_PINS[1]` | 〃 |
| 왼발(발목) | P0.04 | `SERVO_PINS[2]` | 〃 |
| 오른발 | P0.05 | `SERVO_PINS[3]` | 〃 |
| IMU SDA / SCL | P0.26 / P0.27 | BSP 기본 Wire 핀 | 에어밴드에서 사용 중인 핀 |
| 상태 LED | LED_BUILTIN (P0.13) | `PIN_STATUS_LED` | BLE 연결되면 켜짐 |

핀 번호 고르는 기준: variant.h에서 버튼(11, 12, 24, 25), LED(13~16), I2C(26, 27)를 피했다. P0.02~P0.05는 variant.h의 A0~A3이다. **보드 실크/핀맵에서 실제 헤더 위치를 확인한 뒤 다르면 `SERVO_PINS`만 고친다.**

## 3. 전원 — 가장 먼저 확인할 것

| 항목 | 내용 | 상태 |
|---|---|---|
| 서보 전원 | SG90 동작 전압은 판매처 표기 4.8~6V가 일반적. 4개 동시에 움직이면 순간 전류가 1A를 넘을 수 있다 | 쓰는 서보의 데이터시트로 `TODO: 확인 필요` |
| 배터리 후보 | ① AA 4개(6V, 강압 없이 바로 서보) ② 18650 2직렬 + 5V BEC ③ USB 보조배터리(보드) + AA(서보) 분리 | 1주차 결정 |
| 보드 전원 | NU40 DK의 외부 전원 입력 핀과 허용 전압 | `TODO: 확인 필요` — 모르면 USB 보조배터리로 보드만 따로 |
| 신호 전압 | nRF52840 GPIO는 3.3V. SG90은 보통 3.3V 신호로 동작한다고 알려져 있지만 서보마다 다르다 | 실물에서 확인. 안 되면 레벨 시프터 |
| HC-SR04 | 5V 센서라 ECHO가 5V로 나온다 → 3.3V 핀에 직결 금지. 분압 저항 또는 3.3V 버전(RCWL-1601 등) 사용 | 쓸 때 확인 |

**지키는 규칙**
- 서보 전원을 보드의 3V3/USB 핀에서 끌어오지 않는다.
- 처음 전원을 넣을 때는 서보 혼(팔)을 빼고 차렷 각도(90°)를 먼저 확인한 다음 끼운다. 오또 조립 표준 순서와 같다.
- 넘어진 채 다리를 계속 움직이면 SG90 기어가 상한다 → 펌웨어가 넘어짐을 감지하면 펄스를 끊는다.
