# 2026-11-22 오또 Nano: 전원 · 블루투스 문제 해결 기록

## 하고 싶었던 것
건전지만으로 오또를 블루투스(JDY-31)로 무선 조종해서 걷기.

## 결론
- 건전지 종류(망간 → 알카라인) 문제가 아니라, **쉴드가 건전지 6V를 5V로 바꾸는 부분이 서보 4개 전류를 못 버티는 것**이 원인.
- USB 5V를 같이 넣으면 해결된다 → **보조배터리를 Nano USB에 같이 꽂는다** (구매 예정).
- 블루투스 모듈은 고장이 아니다. USB 전원일 때 연결 · 명령 모두 됨.
- 흰색 `RX TX 5V GND` 소켓은 점퍼선이 헐겁게 꽂혀 잘 빠진다. 테이프로 고정하거나 일반 핀을 쓴다.

## 바꾼 것
- 펌웨어 `otto_nano_walk`: 서보 하나씩 켜기, 속도 제한 `v <도/초>`(기본 150), 첫 걸음 진폭 0 → 100% 서서히.
- 조립 지도 `docs/otto-조립-지도.html`: 키트 설명서 회로도 + 오늘 결과로 배선 · 몸 안 배치 · 조립 순서 정리.
  - 초음파 Trig D8 / Echo D9, 도트 DIN D12 / CLK D11 / CS D10, 부저 A0 (제안. 코드는 다음 작업)

## 참고: 노트북에서 시리얼 쓰는 법 (WSL)
- PowerShell `System.IO.Ports.SerialPort`로 COM15(블루투스) / COM12(USB)를 연다.
- WSL에서 `powershell.exe`를 `timeout`이나 파이프로 감싸면 실행이 깨진다. 출력은 파일로 리다이렉트한다.
- 웹 리모컨, 아두이노 IDE 시리얼 모니터가 포트를 잡고 있으면 연결이 안 된다.

## 추가 (00:5x~)
- 사용자가 키트 설명서 회로도 사진과 쉴드 사진을 보냄 → 핀 위치를 사진 방향 그대로 그림으로 정리 (`docs/otto-센서-꽂는-곳.html`).
- 건전지만 켠 상태에서 블루투스 모듈 불이 다시 들어옴. 노트북 COM15 열기 성공, 하지만 `show`에 응답 없음 → TX·RX 선 확인 필요 (USB 업로드 때 뺀 뒤 다시 안 꽂았을 가능성).
- 조립 문서를 하나로 통합: `docs/otto-조립-지도.html` (지금 상태 · 전원 · 핀 지도 · 회로 · 몸 안 배치 · 선 정리 · 조립 순서 · 문제 해결 · 살 것).
- 조립 사진(도트 부착, 쉴드를 상자 위에 걸침, 전원 플러그가 벽 구멍을 통과하지만 잭에 안 닿음) → 조립 지도에 "DC 잭 맞추기"(구멍과 잭 일직선, 넓히기는 마지막 수단)와 "지금 사진 기준 선 정리"(서보선 S자 묶기, 점퍼선 부품별 묶음, BT 모듈 안쪽 벽) 추가.
- 조립 완료 모습 사진(보드는 머리 위, 선은 밖으로) → 리허설용으로 밖 배선 허용. 조건: 보드 평평하게 고정, 선은 등 뒤 한 묶음, BT 모듈은 머리 뒤. 도트·부저·초음파는 스펀지 양면테이프로 고정하는 그림 추가. 사진에서 파란 점퍼선 하나가 빠져 있음(확인 필요).
- 어댑터 플러그가 벽 구멍에 아예 안 들어감 → 머리 위 쉴드 DC 잭에 밖에서 꽂기로 함. 절연 전기테이프로 보드 고정 OK(USB·DC 잭·리셋·핀은 덮지 않기). 도트 불이 꺼짐(코드 없을 때 정상, 전원 확인 필요). 부저 부품을 사용자가 못 찾음 → 부저 생김새 그림 추가.
