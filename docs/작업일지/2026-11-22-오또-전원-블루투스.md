## 결론
- 건전지 종류(망간 → 알카라인) 문제가 아니라, **쉴드가 건전지 6V를 5V로 바꾸는 부분이 서보 4개 전류를 못 버티는 것**이 원인.
- USB 5V를 같이 넣으면 해결된다 → **보조배터리를 Nano USB에 같이 꽂는다** (구매 예정).
- 블루투스 모듈은 고장이 아니다. USB 전원일 때 연결 · 명령 모두 됨.
- 흰색 `RX TX 5V GND` 소켓은 점퍼선이 헐겁게 꽂혀 잘 빠진다. 테이프로 고정하거나 일반 핀을 쓴다.

## 바꾼 것
- 펌웨어 `otto_nano_walk`: 서보 하나씩 켜기, 속도 제한 `v <도/초>`(기본 150), 첫 걸음 진폭 0 → 100% 서서히.
- 조립 지도 `docs/otto-조립-지도.html`: 키트 설명서 회로도 + 오늘 결과로 배선 · 몸 안 배치 · 조립 순서 정리.
  - 초음파 Trig D8 / Echo D9, 도트 DIN D12 / CLK D11 / CS D10, 부저 A0 (제안. 코드는 다음 작업)

## 참고: 노트북에서 시리얼 쓰는 법 (WSL)
- PowerShell `System.IO.Ports.SerialPort`로 COM15(블루투스) / COM12(USB)를 연다.
- WSL에서 `powershell.exe`를 `timeout`이나 파이프로 감싸면 실행이 깨진다. 출력은 파일로 리다이렉트한다.
- 웹 리모컨, 아두이노 IDE 시리얼 모니터가 포트를 잡고 있으면 연결이 안 된다.
