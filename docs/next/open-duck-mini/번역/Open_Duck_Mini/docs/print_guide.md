# 출력 안내

`.stl` 파일은 이 저장소 최상위의 `print/` 폴더에 있습니다.

모든 부품은 일반 PLA, 채움(infill) 15%로 출력합니다. 단, `foot_bottom_tpu.stl`은 TPU, 채움 40%로 출력합니다.
