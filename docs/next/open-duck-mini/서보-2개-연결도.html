그림 1. 최종 연결 (서보 2개 이어 붙이기)

신호 (파란 선) 전원 + (빨간 선) GND (검은 선) USB

서보마다 커넥터가 2개 있고 안에서 서로 이어져 있어서, 기차처럼 줄줄이 연결할 수 있습니다(데이지 체인). 보드의 서보 포트 2개에 하나씩 꽂아도 됩니다. 선 색은 DFRobot 사양서 기준(검정 GND, 빨강 VCC, 파랑 신호)이고, 보드 포트 표시는 상품 사진의 "D V G"를 옮긴 것입니다. 케이블은 한 방향으로만 꽂히는 모양입니다.

그림 2. ID 정할 때는 하나씩

새 서보는 ID가 모두 같아서(보통 1) 둘을 같이 꽂으면 신호가 부딪칩니다. 하나만 꽂아 ID를 바꾸고, 그다음 하나를 꽂아 바꿉니다.

순서

  1. 서보 몸통을 책상에 고정합니다. 양면테이프나 클램프로 붙여서 빠르게 돌 때 튀지 않게 합니다. 혼은 끼워만 두고 아무것도 달지 않습니다.
  2. 보드 점퍼를 B(USB → SERVO)에 꽂습니다. A는 다른 보드의 UART로 제어할 때 씁니다.
  3. 전원을 끈 상태에서 서보 1만 보드 서보 포트에 꽂습니다.
  4. USB-C 케이블로 PC와 연결하고, 장치 관리자에 COM 포트가 새로 생기는지 봅니다. 안 보이면 드라이버가 필요할 수 있습니다(받은 뒤 칩 이름 확인).
  5. 전원을 켭니다(6V 어댑터 또는 7.2V). FD 프로그램이나 configure_motor.py --id 22로 ID를 22로 바꿉니다. 그리고 레지스터 전체를 저장합니다.
  6. 전원을 끄고 서보 1을 뺀 뒤, 서보 2만 꽂아 ID를 23으로 바꿉니다.
  7. 전원을 끄고 그림 1처럼 둘을 이어서 꽂은 뒤, 두 ID가 모두 응답하는지 확인합니다.
  8. 속도 측정: 공장 설정 그대로 한 번, 레지스터 85를 0으로 바꾼 뒤 한 번. 사양값은 6V 42RPM(4.4 rad/s), 7.4V 52RPM(5.4 rad/s)입니다.

꼭 지킬 것

  • 전원이 켜진 채 선을 꽂거나 빼지 않습니다. 이렇게 하다가 보드가 망가진 사례가 있습니다.
  • 7.4V를 넘는 전원을 쓰지 않습니다. 7.5V 어댑터도 피합니다. 사양서상 7.4V를 넘으면 과전압 보호가 걸립니다. 보드에 적힌 "9~12.6V"는 12V 서보 기준 표시입니다.
  • DC 잭과 초록 나사 단자에 전원을 동시에 넣지 않습니다.
  • 나사 단자를 쓸 때는 +와 −를 멀티미터로 확인한 뒤 연결합니다.

확인하지 못한 것

Waveshare 문서 페이지가 이 작업 환경에서 열리지 않아, 포트 표시는 상품 사진과 판매처 설명(점퍼 B = USB 제어, DC 잭 5.5×2.1mm, USB-C, 나사 단자)을 바탕으로 그렸습니다. 서보 포트 2개가 서로 같은 신호선인지, USB 칩 이름(드라이버)은 보드를 받은 뒤 확인해야 합니다.
