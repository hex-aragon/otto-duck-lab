> ⚠️ **조사 메모 (미검증)** — 2026-11-04~06에 만든 계획 초안 3개(단계 구매 PoC안, 70만 원 지원 전제안, 160만 원 국내 조달안)를 한 문서로 합쳤다. 가격은 그때 판매 페이지에 표시된 값이고 **확정 견적이 아니다.** 결제 · 업체 연락 · 예약은 하지 않았다. 아직 조립하거나 실행하지 않은 계획이다.

## 4. 출력 · 조립 · 전원

| 작업 | 방법 | 확정할 것 |
|---|---|---|
| 출력 (PLA 49개 + TPU 2개, 36종 51개) | 유료 출력 업체에 공식 STL · 수량표 · 설정(PLA 15%, 발바닥 TPU 40%) 전달. 발 체결부를 먼저 시험 출력 | 금액 · 납기 · 서포트 제거 · 재출력 |
| 무료 출력 지원 | 지역 메이커스페이스 지원사업은 수량 제한 · TPU 미지원이 있어 **일부 부품만** 맡기는 보조 수단 | 자격 · 납기 |
| 인서트 압입 · 센서 납땜 | 출력 업체에 같이 견적, 안 되면 전자 작업 업체 | 인서트 규격 · 위치 |
| 나사 조립 · 소프트웨어 | 팀 작업 공간 | 공구 · 정리함 |
| 전원 검토 · 하네스 | 경험 있는 업체에 유료 의뢰. 노출형 220V 자가 배선 금지 | 제품 · 정격 · 배선도 · 차단 · 극성 · 부하 검사 |

전기 구조 (개념도, 바로 배선할 수 있는 핀 배선도 아님):

```
게임패드 → Pi → USB 서보 보드 → TTL 통신 → 모터 14개
BNO055 · 발 스위치 → Pi
외부 모터 전원 → 퓨즈 · 물리 차단 · 분배 하네스 → 모터
별도 5V 전원 → Pi
```

## 6. 실행 코드에서 미리 알아 둘 것 (2026-11-04 원본 코드 읽고 확인)

Runtime 저장소는 라이선스 표시가 없어 **코드를 고친 수정본은 공개하지 않고 비공개로 관리한다.** 아래는 코드를 읽고 확인한 사실이다.

| 사실 | 위치 | 영향 |
|---|---|---|
| IMU에서 자이로 · 가속도만 읽고 방향 계산 값은 안 씀 | `raw_imu.py` | 다른 6축 IMU로 대체할 근거 |
| 학습 때 센서 지연 0~3스텝(최대 60ms), 잡음 자이로 ±0.1 · 가속도 ±0.05 | Playground `joystick.py` | 센서 지연이 이 안에 들어야 함 |
| 패드 명령 처리가 항상 켜져 있어 패드가 없으면 멈출 가능성 | `v2_rl_walk_mujoco.py` | 고정 명령 옵션 추가 필요 |
| Ctrl+C로 멈춰도 모터 힘을 끄지 않음 ("TURNING OFF" 출력만) | `v2_rl_walk_mujoco.py` | 힘 끄기 추가, **전원 스위치 필수** |
| 모터 14개 · 1Mbps가 코드에 고정 | `rustypot_position_hwi.py` | 1 · 2단계용 시험 스크립트 따로 필요 |
| `./polynomial_coefficients.pkl`을 상대 경로로 읽음 | `v2_rl_walk_mujoco.py` | 반드시 `scripts/`에서 실행 |
| 가속도 x축 +1.3 보정이 추론 코드에만 있고 학습에는 적용 안 되는 것으로 보임 | `mujoco_infer.py`, `joystick.py` | 실물 값 비교 때 주의, 디스코드 확인 |
| 정책 입력 101개: 자이로 3, 가속도 3, 명령 7, 관절 위치 · 속도 14×2, 이전 출력 14×3, 모터 목표 14, 발 2, 걸음 위상 2 | | 순서를 바꾸지 않는다 |

계획했던 수정 (비공개 수정본에서): 고정 명령 `--fixed_cmd vx vy yaw`, 패드 없으면 패드 코드 건너뛰기, 종료 시 `hwi.turn_off()`, 원하는 ID만 움직이는 `bench_motors.py`.

### 선택: BNO055 대신 누코드 NU40 + 6축 IMU

오또봇 펌웨어의 IMU 코드(`firmware/otto_nu40/imu.h`)를 재사용해 NU40을 IMU로 쓰는 안. 위 첫 번째 사실이 근거다. 오또봇 단계가 끝난 뒤 검토한다.

- 연결: Pi UART(8번 TX, 10번 RX) ↔ NU40 Serial1 (BSP상 P1.01 RX · P1.02 TX — **보드 위 위치 `TODO: 확인 필요`**), GND 공통, 신호 3.3V 확인 (Pi 핀은 5V 불가)
- 전송: 115200bps, 100Hz, 17바이트 패킷 (머리표 `0xAA 0x55`, 번호, 정지 버튼 표시, 자이로 3 · 가속도 3 int16, CRC-8)
- 통과 기준: 10분 손실 0, 왕복 지연의 절반 60ms 이내
- 안 되면 BNO055 구매로 되돌린다
