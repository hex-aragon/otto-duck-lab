## 0. 핵심 원칙

1. **모터 14개를 한 번에 사지 않는다.** 가장 큰 위험(모터 속도, 이슈 #48)을 2개로 먼저 확인한다

4. 출력도 단계별로: 다리 하나 분량 먼저

## 1. 단계 한눈에 보기

| 단계 | 할 일 | 이번에 사는 것 | 예상 지출 | 누적 |

각 단계가 실패하면 **그 단계 지출까지만** 잃는다. 1단계에서 멈추면 10~15만 원(남은 모터 · 보드는 오또 등에 재사용 가능).

단계 구매 때문에 잃는 대량 할인: 모터 5개를 낱개가(43,120원)로 사면 10개 이상 단가(40,700원)보다 **약 1.2만 원 더** 든다. 14개를 다 산 뒤 문제를 발견하는 위험에 비하면 아주 싼 보험이다.

## 3. 1단계 — 모터 2개 시험 (PC만, 파이 없이)

설명서도 모터 설정은 "내 컴퓨터나 파이 중 아무 데서" 해도 된다고 한다. **파이는 아직 안 산다.**

### 살 것

| 품목 | 후보 (11/4~6 표시가) | 비고 |
|---|---|---|
| STS3215 C001 7.4V 1:345 × 2 | 엘레파츠 `EPYLR36T` 43,120원 × 2 = 86,240원 | 저가 ST3215(아이씨뱅큐)는 원본과 같은지 미확인 → **이번엔 원본 계열만** |
| Waveshare Bus Servo Adapter (A) | 엘레파츠 `WVS-25514` 10,032원 | USB 데이터 케이블 포함 여부 확인 |
| 시험 전원 | 아래 중 하나 | |
| 점퍼 · DC 잭 단자 | 집에 있는 것 | |

**전원 고르기 (1단계는 모터 2개라 큰 전원 필요 없음):**

| 선택 | 장점 | 주의 |
|---|---|---|
| ✅ 소형 가변 벤치 전원 (예: 30V 5A급, 밀폐형) | 전압을 7.4V로 정확히 맞추고 **전류 제한** · 전류 표시. 3단계까지 계속 씀 | 가격 `TODO: 확인 필요`. 노출형 SMPS(220V 단자 드러난 것) 사지 말 것 |
| 밀폐형 DC 어댑터 6~7.5V 3A 이상 | 가장 쌈 | 전류 측정 안 됨. 6V면 속도가 낮게 나와 5.24 비교가 어려움 |

### 시험 순서

1. Runtime(`v2` 브랜치)을 PC에 설치(`pip install -e .`), `configure_motor.py --id 22` · `--id 23`으로 하나씩 ID 설정
2. 위치 명령 · 현재 위치 읽기 확인
3. **무부하 최고 속도 측정:** 7.4V에서 큰 각도(예: −90°→+90°) 명령 후 위치를 빠르게 읽어 rad/s 계산
4. 2.7 rad/s 근처로 낮게 나오면 **레지스터부터 의심:** 가속도 · 최대 속도 · 토크 제한 등 설정값을 읽어 기록 (#48 11/1 댓글이 묻는 내용)
5. 손으로 살짝 부하를 주며 전류 기록 → 14개 전원 용량 어림

### 통과 기준 (게이트 1)

| 결과 | 다음 |
|---|---|
| 무부하 ≈ 5 rad/s 이상 | ✅ 2단계로 |
| 2.7 근처, 레지스터 바꿔서 올라감 | ✅ 설정값 기록 후 2단계로 (디스코드 · #48에 공유하면 기여도 됨) |
| 어떻게 해도 2.7 근처 | ⛔ 나머지 주문 보류. #48 · 디스코드에 측정값 공유, 더 빠른 기어비(C046 1:147 등) 검토 — 단 **정책은 C001 기준 학습이라 재학습 필요할 수 있음** |

## 4. 2단계 — 다리 하나 (모터 5개)

### 살 것

| 품목 | 후보 | 비고 |
|---|---|---|
| STS3215 C001 × 3 | 43,120원 × 3 ≈ 13만 | 1단계와 같은 판매처 · 같은 로트 요청 |
| Raspberry Pi Zero 2 W(H) | 디바이스마트 27,720원(입고 예정) / 해외 약 7만 | **Zero W · Pico로 대체 금지.** SD카드 · OTG 케이블 |
| 다리 하나 + 몸통 일부 출력물 | 지원 또는 유료 (PLA 15%, 발바닥 TPU 40%) | 발 체결부를 먼저 시험 출력 |
| 발 스위치 (SS-10형) | 1,300원 × 2~4 | 발 출력물 치수와 대조 |
| 나사 · 인서트 · 베어링 (다리 하나 분량) | 0-6 목록대로 | Loctite 243은 금속-금속 나사에만 |

### 시험

1. 파이: Raspberry Pi OS Lite 64비트, I2C 켜기, usbserial latency_timer=1 규칙 (Runtime README 순서)
2. 모터 3개 ID 설정(20 · 21 · 24 등) → **조립 전에** 영점 위치에서 혼 끼우기
3. 다리 조립, 받침대에 고정 (`print/mods/v2_Jaimes_Mods`의 Stand 참고)
4. Runtime 코드는 모터 14개가 고정돼 있음 → **원하는 ID만 움직이는 시험 스크립트** 필요 (`bench_motors.py`, 비공개 수정본)
5. 기본 자세(hip_pitch −0.63, knee 1.368, ankle −0.784)까지 천천히 → 5분 굽혔다 펴기
6. 파이에서 ONNX 추론 1회 시간 측정 (20ms 안이어야 50Hz)

### 통과 기준 (게이트 2)

- 걸림 · 뒤틀림 · 과열 없음, 출력물 깨짐 없음
- 다리 하나 전류 × 2 + 머리 = 14개 전원 용량 결정
- 추론 시간 20ms 안

## 6. 4단계 — 걷기 (줄 전원)

1. `duck_config.json` 만들기 → `find_soft_offsets.py`로 영점
2. IMU 축 · 부호를 0단계 시뮬레이션 값과 비교
3. 발 스위치 확인
4. `turn_on.py` → **들고 실행** → 받쳐서 제자리(명령 0) → 전진 0.05 → 0.15
5. 게임패드 없이: 고정 명령 옵션(`--fixed_cmd`)을 비공개 수정본에 추가하면 패드 7만 원 절약

**완료 기준:** 받쳐 주지 않고 푹신한 바닥 1m 저속 이동 후 정지, 영상 · 입력 기록.

## 7. 5단계 — 배터리 (마지막)

18650 2직렬 완충 8.4V vs 모터 7.4V 문제(#51)가 아직 답이 없다. 4단계까지 벤치 전원으로 하면서 디스코드 답을 기다린 뒤 결정. 충전 중 자리 비우지 않기, 보호 회로 사용.

## 8. 비용을 더 줄이는 방법

| 방법 | 절약 | 위험 |
|---|---|---|
| 3D 출력 지원사업 (0-1) | 출력비 4~15만 | 수량 · TPU 제한 → 일부만 |
| 파이 · IMU · 패드를 쓰는 단계에서 구매 | 초기 지출 약 17만 연기 | 납기 대기 → 한 단계 앞서 주문 |
| 게임패드 대신 고정 명령 · 웹 조종(오또 웹 리모컨 경험) | 약 7만 | 코드 수정 필요 |
| 벤치 전원 하나로 1~4단계 모두 | 전원 중복 구매 방지 | 14개 동시 전류를 감당하는 용량인지 2단계에서 확인 |
| 해외(알리 등) 모터 직구 | `TODO: 확인 필요` (원본 BOM 단가 14유로) | 가품 · 기어비 · 납기. **1단계 국내품으로 기준값을 잡은 뒤** 비교 |

## 9. 주문 타이밍 (배송 대기 줄이기)

- 1단계 부품 도착 대기 중 → 0단계 마무리 + 다리 출력 시작
- **게이트 1 통과 당일** 2단계 주문 (모터 3 · 파이)
- 2단계 조립 중 게이트 2가 보이면 → 3단계 모터 10개 견적 · 납기 확인 (국내도 주문 수입이면 10영업일 이상)
