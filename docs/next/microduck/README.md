## 마이크로덕이 무엇인가

Hugging Face 산하 Pollen Robotics가 만든 **키 25cm, 800g 미만의 두 발 오리 로봇**이다. 모터 15개로 걷고, 앉고, 공을 차고, 부리로 물건을 집고, 롤러스케이트를 탄다. 동작은 사람이 짠 것이 아니라 **가상 공간(시뮬레이션)에서 강화학습으로 훈련한 결과**를 로봇에 올린 것이다. 내가 새 동작을 훈련해서 올릴 수도 있다.

## 결론 (추천)

1. **완제품을 사전 주문한다.** 399달러이고 한국도 판매 국가에 들어 있다. 다만 지금 주문하면 **2027년 4월 이후 배송**이다.
2. **기다리는 동안 로봇 없이 시작한다.** 시뮬레이터, 학습, 정책 만들기는 전부 로봇 없이 가능하다.
3. **직접 복제해서 만드는 것은 추천하지 않는다.** 금액이 확인된 부품만 해도 약 48만 원이고, 기판 · 3D 프린트 · 컴퓨터 값을 더하면 완제품과 비슷하거나 더 비싸질 수 있다. 공식 설계 파일도 공개되지 않았다.
4. **올해 안에 실물을 꼭 만지고 싶다면** 복제 대신 설계가 공개된 [Open Duck Mini v2](https://github.com/apirrone/Open_Duck_Mini)를 만든다. 다만 키 42cm의 다른 로봇이고 학습 코드도 다르다.

내 PC에서 엔비디아 그래픽카드를 찾지 못했다(`nvidia-smi` 없음). 공식 학습 도구는 엔비디아 그래픽카드가 필요하므로, 학습은 유료 클라우드(`--hf-jobs`)를 쓰는 계획으로 잡았다.
